## 1. Alapok: fájlszerkezet, utasítások, változók
A "Hellp World" C#-ban:
```csharp
using System;

namespace Cucc
{
	class Program
	{
		static void Main(string[] args)
		{
			Console.WriteLine("Szia világ!");
		}
	}
}
```
Java-hoz képest: `using` = `import`, `namespace` `package` (csak itt körbeöleli a kódot, nem a fájl tetején van egysoros deklarációként), `Console.WriteLine` = `System.out.println`. A `Main` itt is kell (nagy M-mel!), és statikusnak kell lennie, mint Java-ban.
