


## A) Mi történt az elméleti órán? 

- **Tömb mint fizikai adattípus:** Azonos típusú elemek sorozata folytonos memóriaterületen. A C#-ban a tömb **referencia típus**. A Stack-en elhelyezkedő tömbváltozó a Heap-en lévő tömbelemek kezdőcímét (referenciáját) tárolja.
- **Indexelés és memóriacím-számítás:** Az \(i\)-edik elem memóriacíme: \(kezdőcím + i \times méret(típus)\). A túlindexelés futásidejű hibát okoz.
- **Többdimenziós tömbök a memóriában:** Folytonos lineáris memóriamodell. Elvi tárolási lehetőségek: sorfolytonos (_row-major_) vagy oszlopfolytonos (_column-major_). Egy \(N \times M\)-es tömb bejárása \(N \times M\) elemhozzáférést igényel. A közvetlen memóriahozzáférés lassú, ezért kiemelt szerepe van a **gyorsítótárak (cache)** megfelelő kihasználásának.
- **Listák mint absztrakt és fizikai adattípus:** Míg a tömb statikus méretű, a lista dinamikus adatszerkezet. A C# `List<T>` osztálya fizikailag **dinamikus tömbként** valósul meg, amely rendelkezik egy belső tömbbel, _Kapacitással (\(K\))_ és _Elemszámmal (\(N\))_.
- **Lista átméretezési stratégiák:**
    - **Additív növelés:** Megteléskor a kapacitás fix értékkel nő. Előnye a minimális memóriatúlméretezés, hátránya a növekvő átméretezési és másolási költség.
    - **Arányos / Geometriai növelés:** Megteléskor a kapacitás egy konstans szorzóval nő (pl. megduplázódik). Előnye, hogy az átméretezések gyakorisága exponenciálisan csökken (amortizált \(O(1)\) beszúrási idő), hátránya a nagyobb memóriafogyasztás.

## B) Mi történt a gyakorlati órán?

- **Tömbök és Listák szintaxisa:**
    - Tömb deklarációja és inicializálása: `new T[méret]` vagy elemfelsorolással `{ ... }`. Üres tömb létrehozásakor az elemek alapértelmezett értéket kapnak (számoknál `0`, logikainál `false`, referenciáknál `null`). Elemszám lekérdezése: `Length`.
    - Többdimenziós tömbök: Pl. `int[,] matrix = new int`, dimenziónkénti méret lekérése: `GetLength(0)` (sorok) és `GetLength(1)` (oszlopok).
    - Dinamikus listák (`List<T>`): Elemszám lekérdezése `.Count`, kapacitás `.Capacity`, elemek hozzáadása `.Add()`, törlése `.Remove()`.
- **A `foreach` ciklus:** Gyömjtemények bejárására szolgál indexelés nélkül. A ciklusváltozó csak másolatot tartalmaz az elemről, ezért a `foreach` ciklussal a gyűjtemény elemei **nem módosíthatók**.
- **Gyakorlati feladatok:**
    1. Francia kártya pakli előállítása (52 elemű tömb).
    2. **Fisher–Yates keverési algoritmus** megvalósítása tömbön.
    3. Keresés tömbben és dinamikus listában ("STOP" kulcsszóig történő beolvasással).
    4. Adathalmaz feldolgozása párhuzamos listákkal (név, életkor, tapasztalat) és átlagéletkor számítása `foreach` ciklussal.
    5. Mátrix generálása és transzponálása (főátlóra való tükrözés).
    6. Horgászverseny fogási mátrixának statisztikái.
    7. **Collatz-sejtés** sorozat generálása `List<int>` használatával és nyomon követése hibakereső (debug) módban.
    8. Mátrix elemeinek elforgatása \(K \times 90^\circ\)-kal.
    9. **Labirintus játék:** útvonal-keresés 2D `bool` tömbben a kezdőpontból a jobb alsó sarokba.

## C) 3. Nagy Jegyzet: Összevont tananyag (Tömbök, Listák, foreach)

```
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 1. Statikus tömb használata
        int[] szamok = new int[] { 10, 20, 30, 40, 50 };
        Console.WriteLine($"Tömb hossza: {szamok.Length}");

        // 2. Kétdimenziós tömb (Mátrix) bejárása GetLength-szel
        int[,] matrix = new int {
            { 1, 2, 3 },
            { 4, 5, 6 }
        };

        Console.WriteLine("\nMátrix elemei:");
        for (int i = 0; i < matrix.GetLength(0); i++) // Sorok
        {
            for (int j = 0; j < matrix.GetLength(1); j++) // Oszlopok
            {
                Console.Write(matrix[i, j] + "\t");
            }
            Console.WriteLine();
        }

        // 3. Dinamikus lista (List<T>) használata
        List<string> nevek = new List<string>();
        nevek.Add("Doom Slayer");
        nevek.Add("Vincent");
        nevek.Add("Mulder");

        Console.WriteLine($"\nLista elemeinek száma: {nevek.Count}, Kapacitása: {nevek.Capacity}");

        // 4. Gyűjtemény bejárása foreach ciklussal (csak olvasásra)
        Console.WriteLine("Nevek a listában:");
        foreach (string nev in nevek)
        {
            Console.WriteLine($"- {nev}");
        }
    }
}
```
