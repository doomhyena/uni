## A) Mi történt az elméleti órán / elméleti háttér?

- **Feltételes ciklusok:** Műveletsorozatok ismételt végrehajtását teszik lehetővé logikai feltétel alapján.
    - **`while` ciklus (Elöl tesztelő):** A feltétel kiértékelése a ciklusmag előtt történik. Ha a feltétel kezdetben hamis, a ciklusmag egyszer sem fut le.
    - **`do-while` ciklus (Hátul tesztelő):** A feltétel ellenőrzése a ciklusmag után történik, így a ciklusmag **legalább egyszer biztosan lefut**.
    - **Végtelen ciklus:** Akkor keletkezik, ha a ciklusfeltétel soha nem válik hamissá (pl. mikrovezérlők esetén tudatos alkalmazás).
- **Számláló ciklus (`for`):** Ismert iterációszám esetén használatos. Három tagja: _inicializátor_ (ciklusváltozó kezdőértéke), _feltétel_ (minden lefutás előtt kiértékelődik) és _iterátor_ (minden lefutás után hajtódik végre, pl. `i++`).
- **Véletlenszám-generálás:** Álvéletlen számokat determinisztikus algoritmusok állítanak elő. C#-ban a `Random` osztály példányosításával (`new Random()`) képezhetünk értékeket: `.Next()` (egész szám), `.Next(felső)` (0 és felső-1 között), `.Next(alsó, felső)`, `.NextDouble()` (0.0 és 1.0 közötti `double`).
- **Matematikai függvények:** A `System.Math` osztályon keresztül érhetők el. Fontosabb műveletek: `Math.Abs()`, `Math.Pow()`, `Math.Sqrt()`, `Math.Log10()`. A trigonometriai függvények (`Math.Sin()`, `Math.Cos()`, `Math.Tan()`) a szöget **radiánban** várják. A matematikai konstansok a `Math.PI` és `Math.E` mezőkkel érhetők el.

## B) Mi történt a gyakorlati órán?

- **Gyakorlati feladatok:**
    1. Számok kiírása 0 és N között, páros számok szűrése `for` ciklussal.
    2. Jelszó bekérése `do-while` ciklussal egyezésig, legfeljebb 3 próbálkozásig.
    3. Véletlenszámok generálása a megadott érték eltalálásáig, próbálkozások számlálása.
    4. Kockadobásos társasjáték kezdőjének eldöntése (hatos dobás N játékossal).
    5. Számtitalálós játék ("gondolt szám") kisebb/nagyobb visszajelzéssel.
    6. Valódi osztók számolása, prímteszt, faktoriális (\(N!\)) és szorzótábla megjelenítése.
    7. Időzítő és visszaszámláló alkalmazás `System.Threading.Thread.Sleep(1000)` késleltetéssel és konzoltörléssel.
    8. Tízesből kettes számrendszerbe átváltó alkalmazás (8 bites blokkokban, big endian formátumban).
    9. **Félkarú rabló játék:** kreditek kezelése, pörgetés Spacebar gombra, nyereményszorzók, tét módosítása nyilakkal és **ASCII art** színes kártyafigurák megjelenítése.
    10. Kriptovaluta árfolyam-szimuláció (\(P_{t+1} = r \cdot P_t + \varepsilon_t\)).

## C) 2. Nagy Jegyzet: Összevont tananyag (Ciklusok, Random, Math)

```
using System;
using System.Threading;

class Program
{
    static void Main()
    {
        // 1. Számláló ciklus (for) és Math osztály
        Console.WriteLine("Négyzetgyökök 1-től 5-ig:");
        for (int i = 1; i <= 5; i++)
        {
            double gyok = Math.Sqrt(i);
            Console.WriteLine($"{i} négyzetgyöke: {gyok:F2}");
        }

        // 2. Véletlenszám-generálás
        Random generator = new Random();
        int kockadobas = generator.Next(1, 7); // 1 és 6 közötti egész szám
        Console.WriteLine($"\nVéletlenszerű kockadobás: {kockadobas}");

        // 3. Feltételes ciklus (do-while) adatellenőrzésre
        string jelszo;
        int probalkozasok = 0;
        do
        {
            Console.Write("Add meg a jelszót (pmp2026): ");
            jelszo = Console.ReadLine();
            probalkozasok++;
        } while (jelszo != "pmp2026" && probalkozasok < 3);

        if (jelszo == "pmp2026")
        {
            Console.WriteLine("Sikeres belépés!");
        }
        else
        {
            Console.WriteLine("Hozzáférés megtagadva!");
        }
    }
}
```
