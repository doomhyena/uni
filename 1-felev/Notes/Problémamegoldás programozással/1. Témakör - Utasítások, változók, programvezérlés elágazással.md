### A) Mi történt az elméleti órán? (Előadás: `pmp_ea_02_valtozok.pptx`)

- **Változók fogalma és attribútumai:** A változó egy névvel ellátott adattároló a memóriában, amely a program futása során átmenetileg vagy tartósan adatok tárolására szolgál. Minden változónak van azonosítója (neve), típusa és értéke. A típus határozza meg a tároláshoz szükséges memóriaigényt, a bináris reprezentációt, valamint a rajta végezhető műveleteket.
- **Memóriaábrázolás és alaptípusok:** A memória legkisebb címzési egysége az 1 bájt (8 bit).
    - **Egész számok:** `byte` (8-bites előjel nélküli, 0–255), `int` (32-bites előjeles, \(-2^{31}\) – \(+2^{31}-1\)), `long` (64-bites előjeles, \(-2^{63}\) – \(+2^{63}-1\)).
    - **Lebegőpontos számok:** `float` (32-bit, 6–9 értékes jegy), `double` (64-bit, 15–17 értékes jegy).
    - **Logikai és karakteres típusok:** `bool` (1 bájt, `true`/`false`), `char` (1 karakter, ASCII/Unicode), `string` (karakterlánc folytonos memóriaterületen, termináló karakterrel).
- **Literálok és elnevezési konvenciók:** A forráskódba közvetlenül beírt konkrét értékek a literálok. A jó kódban beszédes változóneveket használunk a következő konvenciókkal: `camelCase` (változók és paraméterek), `PascalCase` (osztályok és metódusok), `SCREAMING_SNAKE_CASE` (konstansok).
- **Típuskonverzió és túlcsordulás:** A C# erősen típusos nyelv. Az átalakítás lehet **implicit** (automatikus, adatvesztésmentes, pl. `int` \(\rightarrow\) `double`) vagy **explicit** / típuskényszerítés (cast), melynél adatvesztés léphet fel (pl. tört rész levágása). Szöveges adatok konvertálására a `.ToString()` metódus és a `Parse` utasítások szolgálnak. Ha egy változó értéke meghaladja a bitkapacitását, **túlcsordulás (overflow)** következik be (pl. a 8-bites `byte` 255-ös értékéhez 1-et hozzáadva 0-t kapunk).

#### B) Mi történt a gyakorlati órán? (Gyakorlat: `PmP_gyakorlati_jegyzet_01.pdf`)

- **Utasítások és konzolos I/O:** Az egyszerű utasítások pontosvesszővel (`;`) végződnek, az összetett utasításokat (kódblokkokat) kapcsos zárójelek (`{}`) határolják. A parancssori kiírásra a `Console.Write` és `Console.WriteLine`, beolvasásra a `Console.ReadLine` használatos. Az egysoros kommenteket `//` jelöli.
- **Operátorok és elágazások:**
    - **Operátorok:** Aritmetikai (`+`, `-`, `*`, `/`, `%`), összehasonlító (`==`, `!=`, `<`, `<=`, `>=`, `>`), logikai (`!`, `&&`, `||`) és értékadó (`=`) operátorok.
    - **Vezérlés:** Döntéshozatalra az `if`, `else if` és `else` kulcsszavak szolgálnak logikai kifejezések kiértékelésével.
- **Gyakorlati feladatok:**
    1. _Hello World_ kiírása és konzol jellemzőinek módosítása (`Console.Clear()`, háttér- és szövegszín, kurzorpozíció).
    2. Felhasználói név és születési év bekérése, életkor és BMI index kiszámítása (\(BMI = m / h^2\)).
    3. Másodpercben megadott időtartam átváltása `perc:másodperc` formátumra.
    4. Jelszó ellenőrzése zöld/piros üzenettel, jelszómaszkolással (`*` karakterek) és Backspace kezelésével.
    5. Kétoperandusú számológép, valamint **RPN (Reverse Polish Notation)** kifejezéskiértékelő megvalósítása.
    6. Számok szöveges kiírása (0–9), magánhangzó/mássalhangzó teszt és tartálytöltési szimuláció.

#### C) 1. Nagy Jegyzet: Összevont tananyag (Utasítások, változók, elágazások)

```
using System;

class Program
{
    static void Main()
    {
        // 1. Konzol beállítások és kiírás
        Console.ForegroundColor = ConsoleColor.Green;
        Console.WriteLine("=== 1. TÉMAKÖR ÖSSZEFOGLALÓ ===");
        Console.ResetColor();

        // 2. Változók, literálok és típuskonverzió
        int egeszSzam = 42;             // 32-bites előjeles egész
        double valosSzam = egeszSzam;   // Implicit típuskonverzió

        double szelesseg = 13.75;
        int kerekitett = (int)szelesseg; // Explicit casting (13 lesz, adatvesztéssel)

        string bemenet = "100";
        int atalakitott = int.Parse(bemenet); // Szöveg számmá alakítása

        // 3. Programvezérlés elágazásokkal és operátorokkal
        Console.Write("Adj meg egy számot: ");
        int szam = int.Parse(Console.ReadLine());

        if (szam > 0 && szam % 2 == 0)
        {
            Console.WriteLine("A megadott szám pozitív és páros.");
        }
        else if (szam < 0)
        {
            Console.WriteLine("A megadott szám negatív.");
        }
        else
        {
            Console.WriteLine("A szám nulla vagy pozitív páratlan szám.");
        }
    }
}
```
